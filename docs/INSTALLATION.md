# 安装与动作设置

## 运行要求

- Windows 10/11 64 位。
- 桌面版 Adobe Photoshop，安装后至少正常启动过一次。
- Photoshop 动作面板中存在 `组 1 → 水平翻转`。

工具本身是便携程序：从 Releases 下载 ZIP，完整解压后运行 EXE，不需要安装。

## 从已有电脑迁移动作

原电脑：

1. 打开 Photoshop，选择“窗口 → 动作”。
2. 选中动作组 `组 1`。
3. 打开动作面板右上角菜单，选择“存储动作”。
4. 保存为 `.atn` 文件并复制到新电脑。

新电脑：

1. 启动 Photoshop。
2. 双击 `.atn`；若未导入，在动作面板菜单中选择“载入动作”。
3. 确认显示 `组 1 → 水平翻转`。
4. 展开动作，确认只有一个翻转步骤，没有保存、另存为或关闭。

## 重新录制动作

1. 在 Photoshop 中打开任意测试图片。
2. 打开“窗口 → 动作”。
3. 新建动作组，名称为 `组 1`。
4. 在组内新建动作，名称为 `水平翻转`，开始记录。
5. 执行“图像 → 图像旋转 → 水平翻转画布”。
6. 立即停止记录。
7. 确认动作只有一个翻转步骤。
8. 关闭测试图片，不保存这张测试图的修改。

## SmartScreen

个人构建通常没有商业代码签名，Windows 可能显示 SmartScreen 提示。确认文件来自本仓库 Release 后，可选择“更多信息 → 仍要运行”。源码和自动构建工作流都在仓库中，可自行审查和构建。

## 故障排查

### 未检测到 Photoshop

先手动启动 Photoshop 一次，退出后重试。如果仍失败，检查 Photoshop 是否正确注册，或执行 Adobe 安装程序的修复。

### 找不到动作或动作不符合要求

确认名称严格为 `组 1 → 水平翻转`，并且动作中只有一个翻转步骤。

### 无法写入文件夹

确认文件夹不是只读位置、图片未被其他程序占用，并且当前 Windows 账户具有写入权限。

### 恢复原图

1. 删除或移走根目录中本次生成的 `1～N`。
2. 将 `_原图备份_日期_时间` 内的原图移回根目录。
3. 确认文件完整后，再删除空的备份目录。
